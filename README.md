# Neon Siege FPS

A full real-3D FPS prototype built in Python with PyOpenGL and Pygame.

## Features
- First-person 3D camera
- WASD movement and sprint
- Mouse look
- Multiple weapons
- Ammo and reload system
- Enemy waves and boss enemies
- Enemy projectiles
- Health, score, wave progression
- Pause and restart flow
- No external assets required

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python game.py
```

## Controls
- W / A / S / D: move
- Shift: sprint
- Mouse: aim
- Left click: fire
- R: reload
- Q / E: switch weapons
- Esc: pause

## Notes
The game is a single-file prototype and is intended as a playable FPS sandbox in Python.
